# 威智乐园更新公告 / WizPlayground Updates

本仓库只存放威智乐园（WizPlayground）公开版本的 **中英文更新日志**。
两个发行版（用户端、管理端）共用更新提醒渠道。

**GitHub Release 不包含任何安装包**，也不托管源代码归档、个人数据或密钥。
安装包由项目负责人手动上架课程平台。

发布流程：开发方测试、打包及记录版本 → 项目负责人确认课程平台可下载
→ 开发方发布同版本的公开 GitHub Release（Assets 留空）。

客户端启动后自动检查公开最新版本，并允许在首页手动检查；
有新版本时显示更新说明及前往课程平台的入口，不自动下载或安装。

Release tag：vX.Y.Z。中英文更新说明与源项目的 CHANGELOG.md 对应。

Course platform: https://www.aistduy.com/
